# XPX v1.5.1

Version de maintenance, sans changement de fonctionnement.

- Nouveau menu Preferences › Package Settings › XPX (réglages et raccourci
  clavier, ouverts côte à côte : défaut à gauche, utilisateur à droite).
  Aussi dans la palette : « Preferences: XPX Settings » et
  « Preferences: XPX Key Bindings ».
- Organisation interne : le code partagé par les plugins est regroupé dans
  le sous-dossier lib/, conformément aux recommandations de Package Control.

Le package exige Sublime Text 4, build 4200 ou supérieur.
