# XPX pour Sublime Text

Merci d'avoir installé le package XPX.

Les fichiers .xpx et .phc s'ouvrent automatiquement avec la syntaxe XPX.

Principales fonctionnalités :
- coloration (balises, variables, expressions, SQL, JavaScript, CSS) ;
- navigation dans les fonctions : Ctrl+R, Ctrl+Maj+R, F12, survol ;
- complétion des balises, attributs, valeurs et fonctions du projet ;
- fermeture et indentation automatiques des balises XPX.

Couleurs : le package fonctionne avec tous les color schemes. Pour personnaliser
les couleurs XPX : Preferences > Browse Packages... > XPX >
XPX.sublime-color-scheme.example

Documentation XPX : https://www.xpx-technologies.net/balise_xpx.html
