# XPX v1.5.0

Nouvelle version entièrement réécrite, conforme aux conventions actuelles de
Sublime Text 4 (build 4200 ou supérieur).

## Nouveautés

- Coloration : variables imbriquées ($tab[indice]$, $nom(1,len)$), expressions
  (expr="..."), SQL de <sql query="...">, balises et variables XPX dans le
  JavaScript et le CSS. Un « $ » isolé n'est plus pris pour une variable.
- Navigation dans les fonctions de tout le projet : Ctrl+R, Ctrl+Maj+R, F12,
  Maj+F12, et aperçu au survol (définition, appels, doublons).
- Complétion : balises, attributs, valeurs, noms des fonctions du projet dans
  exec="...", paramètres de la fonction appelée, variables internes.
- Variables d'arborescence ($gRep…$) : résolution des chemins des <include>,
  F12 pour ouvrir le fichier inclus ou la définition d'une variable, survol
  (chemin réel, fichier introuvable, $gUrl…$ dans un include), complétion des
  chemins. Réglages : xpx_functional_folders, xpx_definition_files, xpx_site...
- Aide au survol des balises XPX avec lien vers leur documentation en ligne.
- Fermeture automatique des balises qui ignore les balises XPX inline.
- Indentation automatique des blocs XPX.
- Commande « XPX: Fermer les balises inline par « /> » ».
- Fichiers de debug (.debug) : nouvelle syntaxe XPX Debug (début de chaque
  balise surligné, erreurs et avertissements), F12 vers le code source, et
  suivi d'une variable : historique de ses changements de valeur dans un
  panneau (set, get format, get token), avec noms calculés résolus et
  portées (GLOBAL, fonctions) — clic droit sur la variable.

## Important : couleurs

Les noms des scopes XPX ont changé et le package n'impose plus de color scheme.
Si vous aviez personnalisé les couleurs XPX dans votre color scheme, reprenez
l'exemple fourni : Preferences > Browse Packages... > XPX >
XPX.sublime-color-scheme.example

## Réglages renommés

- enable_self_closing_xpx_tags  ->  xpx_self_closing_tags (défaut : true)
- disable_default_completions   ->  xpx_completions (défaut : true)

Documentation complète : README du package.
